The digital signal processor, usually shortened to DSP, is a processor inside the inverter. Fronius inverters report status code 460 when the reference voltage source that feeds the DSP is running outside its tolerances. Fronius Primo and Symo inverters report status code 461 when there is an error in the DSP data memory. On the Fronius Symo, status code 518 means an internal DSP malfunction, and the inverter shows a warning message on its display.
