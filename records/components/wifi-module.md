The Wi-Fi module is a wireless communication part built into the inverter. It lets the inverter join a network, for example through a router, and connect directly to a smart end device; a WPS function supports automatic connection. On some SMA units the Wi-Fi interface may be missing because of semiconductor supply shortages. In that case, use the standard Ethernet interface, or an Ethernet-connected Wi-Fi repeater if Wi-Fi is required. When present, the Wi-Fi interface is on when the unit is delivered and can be turned off if WLAN is not used. The main failure mode is a defective Wi-Fi module inside the inverter. The inverter shows an event message while it updates the Wi-Fi module and another if the update fails. If a Wi-Fi update fails, retry it. If the message comes back, contact the manufacturer's service. On some other inverters, the built-in Wi-Fi option needs an external antenna that is bought separately and fitted during installation.
