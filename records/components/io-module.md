name: I/O module
---
The I/O module is an SMA module that exchanges data with the inverter over a device-internal communication link. If that internal communication fails, the inverter shows event 7622, No communication with the I/O module. When this event occurs, the inverter disconnects from the utility grid for safety reasons, so production stops. The Sunny Tripower CORE1-US inverter comes with two module slots on its communication assembly for connecting add-on modules, which are sold as accessories. Two identical modules must not be installed in these slots.
