Sunny Portal powered by ennexOS is an online monitoring and management portal. It works with the SMA Data Manager M (EDMM-10 or EDMM-US-10) and the SMA Data Manager M Lite (EDMM-10.A). Its user manual covers setting up PV systems whose SMA inverters run ennexOS. In the portal you can group systems together and split a system into sections. You can choose the data resolution: high stores data every 5 minutes, and low stores it 6 times a day. The portal calculates a performance ratio and raises an alert when it crosses the thresholds you set. It can send a daily system report and an event report, both available with either data manager. The portal can also change parameters across the whole system on connected devices that support it, so check which devices are affected before you push a change.
