Generac PWRview is a mobile app that system owners use to manage circuits connected to a Generac PWRmanager. You can get it from Google Play or the Apple App Store. Log in with the email address the PWRcell system is registered to. The installer must wire, configure and register the PWRmanager before the app can manage circuits. In the app you can set up automatic control, or switch loads directly from the Circuits List screen and the circuit control panel. To connect to the PWRmanager locally, tap SYSTEM SETTINGS AND STATUS, then tap CONFIGURE CIRCUITS. This opens the PWRmanager's embedded web page for configuration. If a login prompt appears, enter admin as the user and the password printed on the information label on the touch-safe cover. You can also connect to the PWRmanager locally with a web browser, without the app.
