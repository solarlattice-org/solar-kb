Sunny Design is SMA planning software for designing PV systems with or without self-consumption, off-grid systems, PV hybrid systems and complete energy systems. It recommends a combination of PV arrays and inverters that comes as close as possible to the required power class, energy yield and efficiency. The tool can also estimate and optimize self-consumption, size cables, evaluate efficiency and, for hybrid and off-grid systems, configure gensets. Registered users can save and manage projects, run harmonics calculations and use SMA 360° documents; anonymous users cannot. Tariff management, storage simulation for peak load shaving, consumption and load profile analysis, and advanced project documentation are available only in Sunny Design Pro. Designing an energy system or using the advanced settings needs an extra access authorization for Sunny Design Pro. Projects can be exported and re-imported as .sdp3 files through the Manage Projects page. Systems planned in Sunny Design can be imported into Sunny Portal, where they can be configured if needed and reused during commissioning.
