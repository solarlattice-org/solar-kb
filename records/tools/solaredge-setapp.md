SetApp is a SolarEdge mobile application that technicians use with SolarEdge inverters. It is used for commissioning and for setting up inverter communication. SetApp can configure a SolarEdge inverter or Commercial Gateway so that a non-SolarEdge monitoring device can monitor it. The app gives access to SolarEdge support, including the Knowledge Base and opening and viewing support cases. The app gets new inverter firmware over the air, so no SD card is needed for software updates. Automatic updates must be turned on, or the app is blocked after 5 weeks. Only SolarEdge communication products are supported, and communication options should be connected while the inverter and gateway are powered down. SolarEdge Academy offers a guided SetApp simulation that you can practise on without connecting to a real inverter.
