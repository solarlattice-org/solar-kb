A voltage detector is a field instrument used to confirm that inverter terminals are dead before work starts on them. In the FIMER inverter manuals it is used for the AC-side voltage absence test, checking phase to ground, neutral to ground and phase to neutral on the AC terminal blocks after lifting the protective sheet. The same instrument is used for the DC-side voltage absence test: check each positive input to ground, each negative input to ground, and positive to negative on every input section, but only once all earlier steps in the procedure are done. On larger FIMER string inverters it is also used to confirm there is no voltage on the mid bulk point, measured inside the power module. SMA service and board-exchange manuals list a 2-pole voltage detector without its own voltage source as additional equipment that is not supplied with the product. For PV array work, SMA calls for a detector able to measure up to 1000 V DC, and says to check array polarity and maximum voltage by measuring the open-circuit voltage.
