The Locus Energy Kiosk is a public web interface that shows solar performance data and educational content, mainly as a marketing display for the system owner. It can show current power output and historical generation for one system or a group of systems in an animated layout, with the customer's logo and project images. It is built for widescreen high-definition monitors and touchscreens and works in all major browsers. System data on the display refreshes every 15 minutes, so it shows near-real-time performance rather than live readings. If a preconfigured mini PC is purchased, Locus Energy can troubleshoot the kiosk through remote desktop support. Kiosk displays can show environmental equivalencies for the energy produced. In PowerTrack, you open kiosk links from the Site Overview Custom Displays tab and set them up in the Site Config Custom Displays tab. A custom kiosk can be built on the Locus API, but in that case Locus Energy does not build the user interface. Contact the account manager to ask about cost and setup.
