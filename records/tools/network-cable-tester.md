A network cable tester is a field instrument for checking Ethernet communication cabling. It is on the recommended or required tool lists for installing, operating and maintaining monitoring systems. Use it to confirm cable and crimp quality whenever you terminate CAT5, CAT5e or CAT6 cable in the field instead of using molded cables. One example is the run from a monitoring gateway to the router, switch or firewall. It is usually carried with an RJ45 termination or crimp tool and outdoor-rated shielded STP Cat5 or Cat5e cable for data acquisition installs. When a data logger loses communication, a bad network cable is one possible cause. Check the cable as well as the logger and the site network, and retest with a known working Ethernet cable. If the gateway's link and activity LEDs are dark, check that the gateway has power before you blame the cable. Those LEDs only light when the gateway is powered.
