A PV connector crimping tool is a hand tool that crimps the metal contacts of MC4-type PV connectors onto DC cable ends. Inverter manuals list it as a required installation tool for making up the DC input cables that run from the PV strings to the inverter. Huawei names model PV-CZM-19100 for this job and lists a separate open-end spanner for removing MC4 connectors from the inverter. Some manuals call for a crimper specific to the connector series, such as MC4-Evo2 crimping pliers for 4-6 mm2 conductors or crimping tool H4TC0002. Some manuals also use general crimping pliers to crimp terminals, and optionally ferrules, on the inverter wiring. The tool that crimps RJ45 Ethernet plugs for communication cables is a separate crimper and is listed on its own.
