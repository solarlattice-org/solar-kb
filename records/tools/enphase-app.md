The Enphase App is Enphase's monitoring app for system owners. It was previously called the Enlighten App. Enlighten is Enphase's web-based software for monitoring and analysis. The gateway (Envoy or Envoy-S) gathers production and performance data from the microinverters over the site AC power lines and sends it to Enlighten over an internet or cellular connection. Owners use the same Enphase App for both commercial and home Enphase Energy Systems, and an owner with several systems can see all of them from one login. The app has generator modes for systems with IQ Battery and IQ8 Series equipment. The Wi-Fi connection of an IQ Gateway can be set up from the Enphase App or the Enphase Installer App. Recent gateway software releases improved the error messages and accept more characters in Wi-Fi credentials. Onsite setup and commissioning are done in the separate Enphase Installer App, formerly the Installer Toolkit. Fleet management is done in the Enphase Installer Portal, formerly Enlighten Manager.
