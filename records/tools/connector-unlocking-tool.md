A PV connector unlocking tool is a hand tool for releasing the latch on mated DC connectors so they can be pulled apart, for example to remove MC4 DC connectors from an inverter. The tool is specific to the connector type: Huawei lists a PV-MS open-end spanner for MC4 connectors and a separate Amphenol spanner, model H4TW0001, for Amphenol Helios H4 connectors. Enphase makes its own IQ Disconnect Tool, Q-DISC-10, for separating IQ Cable connectors on its microinverter systems. The O&M procedure for isolating modules and string wiring uses this tool: first turn off the inverter, switches and combiner boxes, then use a DC clamp meter to confirm no current flows in the string, then unlock each module connector with the right tool. Never open a connector while current is flowing, and if modules are removed, make sure the equipment grounding stays intact for the modules that remain.
