The DuraTrack HZ v3 is a solar tracker product family made by Array Technologies, Inc., based in Albuquerque, New Mexico. Array Technologies publishes both an installation guide and an operations and maintenance guide for this tracker. The tracker has a stow function. Remove the cross-rods before stow runs, because leaving them in place can damage the tracker's structural parts. The tracker motor screen shows a stow device register. Before the first start-up, call Array Technologies for help. If a problem is still there after the troubleshooting steps, or the same problem comes back on the same tracker, contact the manufacturer.
