In secure power supply operation, the inverter powers a dedicated outlet using current from the PV system. While this mode is active, the display shows the message SPS-mode active. The green LED flashes in a slow pattern, on for 1.5 s and off for 0.5 s, while the inverter supplies the outlet. The mode is turned on and off with the switch for secure power supply operation. To test it, switch off the AC miniature circuit breaker, then turn the switch on and check that the load on the outlet starts. This can take up to 30 seconds. If the load does not start, check the wiring of the socket and the switch, and make sure SMA Backup Start is installed correctly. If it still does not start, contact Service. The switch can stay on if the secure power supply is needed all the time. It does not have to be switched on and off each time. The display shows P: Overload when the load on the secure power supply input is too high. SPS AC overvoltage means an AC source has been connected to the secure power supply socket. Both of these need action.
