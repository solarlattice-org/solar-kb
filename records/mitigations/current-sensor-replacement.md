- AC Current Sensor Replacement

On SMA Sunny Island units, an event reporting a missing, disconnected or defective current sensor tells the operator to contact Service. Yaskawa Solectria publishes customer-facing instructions for replacing the AC current sensor, including a version for the XGI 1500 inverter. The Yaskawa procedure has steps for cutting zip ties and for removing the AC and DC customer connections and the DC switch hardware, each with a stated socket size and torque. To install the new sensor, slide the AC bus bar through its centre with the arrow pointing toward the IGBT, then mount the sensor on the drop-in panel with M4 nuts. Next, fasten the AC bus bars to the IGBTs, and fasten the red inductor wires and the bus bars to the isolating standoffs, tightening each to the specified torque. After replacing a battery current sensor in a Sunny Island system, calibrate the sensor as described in the commissioning section of the installation manual.
