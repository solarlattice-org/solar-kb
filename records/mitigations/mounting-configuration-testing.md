name: Mounting configuration testing
---
Mounting configuration testing means having an accredited test laboratory test a non-standard way of mounting modules, such as facade mounting, before it is used. It is listed as an optional preventive action against bad module clamping and against inappropriate or defective mounting structures. The sources pair it with regular system inspections, which should be done as well. It adds to the recommended preventive steps but does not replace them: use only compatible clamps or mounting structures, follow the manufacturer's mounting instructions, and check local wind and snow loads. In the field, both of these mounting failures are detected by visual inspection.
