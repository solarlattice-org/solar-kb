id: mit:meter-wiring-check
type: Mitigation
name: Meter wiring check
---
First confirm that the meter is connected correctly, then check whether its input and output wiring has been swapped. If an existing system is enabled, also check that the rated power set for the existing inverter is correct. Wrong CT installation or meter wiring is a common installation failure, and the system will not work properly until it is fixed. Read each CT label for its ratio and its flow-direction arrow, and make sure each phase's voltage wiring goes to the same phase as its current wiring, with the polarity matching the sign convention. For each meter, measure the resistance between the positive and negative terminals of every CT pair; it should be about 0 ohms. Then set the CT ratio in the meter interface and record it. This check covers only wiring and installation, not meter accuracy. If a meter's communication is faulty, consult the meter manufacturer.
