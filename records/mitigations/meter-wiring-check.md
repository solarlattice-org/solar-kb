name: Meter wiring check
---
A meter wiring check confirms that the energy meter and its current transformers are connected to the inverter system correctly. First check whether the meter is connected wrongly, then check whether its input and output wiring has been swapped. If an existing system is enabled, also check that the rated power setting of the existing inverter is correct. When wiring CTs, read the arrow on each CT label for the direction of flow and its CT ratio. Make sure each phase's voltage wiring matches the same phase of current wiring, with the polarity correct. For each meter, measure the resistance between the positive and negative terminals of every CT. Then set the CT ratio on the meter to match the installed CTs. Incorrect CT installation or meter wiring is a common point of installation failure, and the system will not operate correctly until it is fixed.
