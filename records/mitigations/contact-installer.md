Fronius tells users to contact the system installer when certain status codes keep coming back. These include insulation errors on the solar modules (codes 502 and 475) and a faulty RCMU sensor (code 474). Both point to a possible loss of electrical insulation. With code 475 the inverter stops feeding energy into the grid. With code 502 the inverter only shows a warning on the display. Fronius status code tables mark which persistent codes should go to the system installer and which need a Fronius-trained service technician. Solis and CSI inverter manuals give the same fix for an initialization system fault or a failed relay check: restart the inverter or contact the installer. When you contact the installer, give the device serial number and the event number. Some events can only be cleared by the installer working on the device itself. The installer usually provides the overall system warranty and can replace failed parts, such as an inverter, under the manufacturer's warranty. If the installer or dealer cannot be reached or cannot help, contact the manufacturer's customer service instead.
