name: Complete device configuration
---
Complete device configuration means working through every required setup step for the inverter and its connected devices before the system goes into normal operation. In one commissioning app, the device configuration step lists all inverters connected through the data logger. The technician follows the on-screen setup instructions and completes all required settings before moving on. When the configuration is complete and the technician moves to the next step, the system starts an installation diagnosis on its own. On some inverter user interfaces, the Device Configuration menu has a Settings option. From there a configuration can be saved to a file, or loaded from an existing file by following the dialog. In some monitoring portals, devices are registered under Configuration and Device management, using a step-by-step registration wizard.
