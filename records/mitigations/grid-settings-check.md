For a frequency fault, read the measured frequency on the inverter LCD. If the value is within the limit, restart the inverter. A similar Solectria procedure blames out-of-range grid frequency or loose AC connections. It says to watch for 10 minutes to see if the alarm clears by itself, check the frequency and AC wiring, and contact customer service if the error stays. A wrong grid standard or country data set can make the inverter run improperly, damage it or stop it from running at all. On SMA units it can look like the inverter is waiting for grid voltage. Only certified personnel should set the grid standard, and only to a configuration approved for the location. Settings meant for grid operators should not be changed unless you are specifically told to. To verify the programmed grid protection settings, open the inverter's view menu and compare each setpoint with the required values. O&M guidelines say plant control settings should be monitored at the inverter and grid injection levels. They list a yearly check of inverter parameters as a minimum requirement.
