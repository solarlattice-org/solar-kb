License certificate renewal means getting a new license certificate and loading it when the current one is about to run out. To clear the alarm, apply for a new certificate and then load it onto the inverter. Licenses are managed under Function Menu, Maintenance, License management. That screen shows the license status, and a new license is loaded there when the status reads No license. Before you replace a device, revoke its current license. Revoking it produces a revocation code, which you need to apply for the new device license. For software licenses such as the Yaskawa Remote Access Portal, an expired license shows a notice at sign-in and sends the user to a payment page to renew. To upgrade or downgrade the license, contact technical support. The sources give no figures for how well renewal works. They only say that if the certificate is not renewed, the licensed feature stops working.
