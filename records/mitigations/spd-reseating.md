id: mit:spd-reseating
type: Mitigation
name: SPD module reseating
---
SPD module reseating means pulling the plug-in surge protection module out of its socket and putting it back in. Inverter manuals list it as a fix for the DC SPD warning (Warn0040) and the AC SPD warning (Warn0100), which are raised when a surge protector may be exhausted. Start by checking the SPD status indicator by eye. Reseat the module only if the indicator is green. If the indicator is red, reseating will not help. Replace the SPD module instead. On stand-alone SPDs, a red LED together with an audible alarm points to protection that is compromised or lost after a significant surge event. The listed fix is replacement. If one phase is red because of an extended temporary overvoltage, find and correct the overvoltage source before you install a new SPD. If the warning is still there after reseating, contact the manufacturer's post-sales service.
