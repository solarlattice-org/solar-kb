This action swaps the inverter's communication assembly for a new one. You remove the old assembly first, then fit the replacement. Before taking the old assembly out, check the status of the new one so you know the swap can actually be done. Write down the inverter settings before you start, because they are not carried over: NetID, system time, passwords, automatic firmware update settings and the fed-in energy offset all have to be re-entered afterwards. The event counter, event log and yield data logger are lost for good. To install it, seat the new assembly in the DC connection unit, fasten it with the supplied screws to the specified torque, plug every connector back into its socket, and refit any communication modules. Commission the inverter without connecting it to the local network first, and allow time for the new assembly to sync with the inverter. Then update the network settings, join the local network, and reconfigure the communication modules if needed. The new assembly comes with a new identification key, registration key and Wi-Fi password, and its label goes over the old one. Any QR code on the enclosure lid for Wi-Fi access stops working after the swap.
