SGIP, the Self-Generation Incentive Program, is a California incentive for customer-sited generation and storage, and storage guides count it as a value stream next to the federal investment tax credit. To qualify, a site has to be eligible for SGIP, meaning it is served by an investor-owned utility, gets PG&E delivery, or is in SoCal Gas territory. Start by registering as an SGIP Developer. Fill in the online registration form, which asks for company profile and account administrator details, and send it to the SGIP Support Team. Approval can take over a month. Once a developer is approved, Energy Solutions can set up portal logins for other users. Each application starts with the Program Administrator territory. This field cannot be changed after the Reservation Request Form is submitted. Submit the Reservation Request Form, then mail an application fee of 5% of the reservation amount. Within 90 calendar days of the conditional reservation, send proof of project milestone with an executed contract. You can file the Incentive Claim Form only after you receive the permission to operate letter. The deadline is 18 months from the conditional reservation, and it can be extended if the project is delayed. After the claim is approved, the program administrators arrange an onsite inspection and factory test before the upfront payment is made. SoCal Gas requires scanned wet signatures, while the other administrators accept digital ones.
