id: meas:low-soc-start-event-message
type: Measurement
name: Low charge start event
aliases:
- Event 9345
---
This signature is an inverter event message saying the battery charge is too low for the start procedure. In the SMA event list it appears as event 9345. It means the battery state of charge has dropped below what the inverter needs to start up. Once this happens, the inverter can no longer recharge the battery on its own. A qualified person must charge the battery right away. If the battery is from SMA, contact SMA Service and ask for a manual charge. If it is from another manufacturer, contact that manufacturer.
