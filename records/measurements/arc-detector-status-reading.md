The arc detector status reading is a menu item on the inverter that shows the present state of arc detection and arc interruption. The same manuals list an Arc Detection item for checking the arc detection and interruption function. Read the status on the inverter display to confirm whether arc detection is active or has been disabled. A defective or faulty arc detector is reported separately under status code 249, which points to an arc detection board failure.
