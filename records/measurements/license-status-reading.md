On Huawei SUN2000 inverters, you read the license status on the License management screen, found under Function Menu, then Maintenance. The screen shows one of three states: Normal, Deregistered or No license. If the status is Normal, the license can be revoked. If it is Deregistered, the revocation code can be exported and viewed. If it is No license, a license has to be loaded. Revoke the current license before you replace a device. Revoking it creates the revocation code needed to apply for the new device's license. Checking the license status is part of the regular inspections done once an inverter is in service. On the Yaskawa Remote Access Portal, an expired license shows up as a notice when you sign in. The notice sends you to SolrenPay, where you can pay to renew. To upgrade or downgrade a portal license, ask Technical Support to update it.
