id: symptom:boost-startup-timeout
type: Symptom
name: Boost converter startup timeout
aliases:
- Ramp Fail
- Ramp Fault
- E011
---
The inverter shows error code E011, labelled Ramp Fail or Ramp Fault, and an alarm or yellow LED lights up. The code means the DC-DC booster stage took too long to reach its operating regime during start-up. The manufacturer treats this as an error inside the inverter that cannot be checked from outside. Check first by switching the inverter off and back on. If the error comes back, contact customer assistance. Do not confuse it with E017 Start Timeout. That code concerns start-up of the DC-AC inverter stage, and it can come from outside the inverter, for example limited irradiance with input voltage just above activation. Sporadic E017 in low light is usually external. E017 that recurs under strong irradiance, with input voltage well above activation, calls for customer assistance.
