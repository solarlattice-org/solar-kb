---
id: symptom:timezone-database-update-failure
type: Symptom
name: Time zone update failure
---
The inverter reports event 7354 when it fails to update its time zone database. Before this, event 7353 may appear, showing the inverter is updating the time zone database. The sources give no hardware cause or failure mode for this message. They treat it only as a failed update. First, retry the time zone database update. If the message shows up again after the retry, contact the manufacturer's Service.
