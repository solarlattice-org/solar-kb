---
id: symptom:loose-module-fastening
type: Symptom
name: Inadequate module fastening
---
This symptom is seen at the mounting: a module that is not held firmly enough by its clamps, or a module or frame that a clamp has damaged. It is listed under the Bad Module Clamping failure, which is classed as a mounting component defect. Visual inspection is the detection method given for this defect, so start by checking the clamps and module edges on site. Check whether the clamp type suits the module and mounting structure, because unsuitable clamps with sharp edges can damage glass/glass modules. Also check that the clamps are long and wide enough and that their position, type and number match the manufacturer's manual. Look for screws that are too loose or too tight, because both are named as typical mounting-phase errors. The root cause is usually that the manufacturer's installation instructions for the module and mounting structure were not followed, but the defect can also start in production or appear during operation.
