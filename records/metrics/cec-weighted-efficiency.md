CEC weighted efficiency is an efficiency figure that manufacturers give as a percentage in the technical data tables of inverter manuals. Datasheets often shorten it to the symbol ηCEC. It is listed in a separate row from maximum efficiency, so the two values are different ratings for the same unit. The value can depend on the AC grid voltage, so some manuals list it separately at 240 V and at 208 V. Microinverter manuals may give it only as a maximum value for a stated connection, such as 240 VAC single-phase. For some central inverters the manufacturer says the value was measured with the unit's own power supply (energy self-sufficiency) included. The figure also appears for battery inverters and battery storage systems, not only for PV string inverters.
