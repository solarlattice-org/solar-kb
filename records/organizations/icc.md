The International Code Council (ICC) is a code organization. Equipment manuals name it next to NFPA as a source of installation codes that local jurisdictions adopt. One installation manual for a three-phase storage inverter says certain publications can guide an installation where no local laws or standards apply, in places that recognize NFPA and ICC codes. That list includes the International Building Code, the International Fire Code and the International Residential Code. It points to the ICC website, iccsafe.org, as the place to get the International Building Code. Battery storage installation manuals point to approved changes in Section 321 of the 2021 International Fire Code, which covers storage of lithium-ion and lithium metal batteries. Those manuals tell installers to ask the local fire code official about upcoming fire code changes, and the manufacturers say not every code applies to every product. Always check with the local Authority Having Jurisdiction for the codes and editions in force at the site.
