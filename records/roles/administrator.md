In SMA Sunny Portal user management, the system administrator ranks above the guest, standard user and installer roles. The system administrator is the only role that can see the user management view. To replace a Sunny Home Manager 2.0 you need system administrator rights. The new unit also has to be connected to the router and powered. Administrators and installers can both import data or parameters, change the system password and set up communication monitoring. Adding a Sunny Home Manager 2.0 to the SMA EV Charger web interface after initial setup needs administrator rights, so owners are told to contact their installer. On the Yaskawa Solectria Remote Access Portal, the tenant administrator has full administrative rights: creating, editing and deleting users, and assigning roles and privileges. Yaskawa Solectria Technical Support names the tenant administrators at first setup and is the only party that can create roles. To find out who holds admin rights on an SMA ID company account, a logged-in member opens the Employees section of their SMA ID profile and looks for the Admin user role.
