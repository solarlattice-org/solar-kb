On SMA products, service access lets a service user authorized by SMA open the product user interface when the product malfunctions or when warranty work is carried out. Warranty services require service access to be switched on, and it should stay permanently on if fast emergency service must be possible. It can be switched on or off at any time. A User or Installer turns it on under User settings, Access rights, Service. The choices are Yes permanently, Yes temporary with an expiry date, or No. Then click Save. For the SMA Data Manager M, SMA recommends switching service access on during registration. If service access is not configured, the service user cannot reach the system, and a VPN connection may also be needed. To enter it, type the CAL command at the Access Level 2 prompt, and only when SEL tells you to. Type 2AC to go back to Access Level 2.
