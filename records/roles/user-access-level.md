The User access level is the basic login group on monitoring and inverter interfaces. It sits below the Installer and Administrator groups. On SMA Data Manager M devices, the User group cannot turn on service access. Only the Administrator and Installer groups have that right. Some SMA procedures only ask you to open the user interface and log in as User. If a login fails because the user is not authorized for the device, contact the administrator to get access.
