IEC 61850 is a vendor-independent, Ethernet-based communication standard. It was developed for electrical substations so that self-describing devices from different manufacturers can work together in one integrated system. Client-server data exchange uses the Manufacturing Message Specification (MMS). Part 8-1 maps it onto ISO/IEC 8802-3 Ethernet, and GOOSE messages are used for fast exchange between peer devices. The standard is a set of documents. It covers the configuration description language for substation IEDs (part 6), the abstract communication service interface (part 7-2), logical node classes (part 7-4), sampled values (parts 9-1 and 9-2) and conformance testing (part 10). The SEL RTAC can serve as the central controller in an IEC 61850 system using GOOSE and MMS, and it supports Editions 1 and 2. Its MMS server can convert data collected over legacy protocols into MMS. For distributed energy resources, IEC 61850-7-420 defines the information models for monitoring and control. IEC 61850-8-2 defines a protocol based on Internet protocols. Commercial IEC 61850 configuration tools include client and server test suites, the OMICRON IEDScout test client and an SCL editing tool.
