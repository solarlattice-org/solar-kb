IEC 61850-7-420 is an information model, not a transport. It defines the data objects used to monitor and control distributed energy resource (DER) devices. The same document also gives guidance on how DER functions should be carried out. The model data can be sent over IEC 61850-8-1 or over IEC 61850-8-2. IEC 61850-8-2 is a standardized protocol built on Internet protocols. IEC TR 61850-80-3 gives guidance on using web protocols to exchange this data. Profiles of the IEC 61850-7-420 model can also be mapped onto DNP3 (IEEE Std 1815) or onto SunSpec Modbus.
