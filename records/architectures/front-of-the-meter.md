A front-of-the-meter (FTM) system is an installation that sits in front of the meter. Metering guidance lists it as its own project type, separate from behind-the-meter and backup power systems. Energy storage can be installed this way either on its own or paired with a solar PV system. A typical FTM metering layout can include a site meter, an energy storage meter, a PV meter and an auxiliary meter. FTM systems have no site load. The site meter is used to get the best overall system performance in whatever grid programs the system takes part in. The auxiliary meter measures the energy used by auxiliary equipment, mainly the storage HVAC unit but also the power controller. Some storage products power their HVAC internally and do not separate those loads. Check with the project manager that every auxiliary load the utility requires is being metered. Not every meter model is listed as compatible with every meter position in an FTM installation, so check the compatibility table before buying meters.
