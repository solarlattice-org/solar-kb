This service is a three-phase, four-wire grid connection: three line conductors and a neutral conductor, with a nominal 400 V between any two line conductors. On SMA inverters this connection is selected as the grid type GriTyp3P4W_400V_LL, which is defined by its line-to-line nominal voltage. Three-phase string inverters such as the SMA Sunny Tripower X 12 to 25 list 230 V / 400 V as one of their nominal AC voltages. The same inverters also accept the nearby 220 V / 380 V and 240 V / 415 V systems, so check the actual local grid voltage before you set the grid type.
